# \ud83c\udf89 JLC Group - Application de Gestion d'Int\u00e9rim

**Stack**: FastAPI + React + MongoDB | **Architecture**: Clean Architecture | **Statut**: MVP Complet \u2705

## \ud83d\udcca Vue d'ensemble

Application complète de gestion d'int\u00e9rim pour JLC Group avec:
- \u2705 **Authentification multi-r\u00f4les** (Admin, Agence, Entreprise, Int\u00e9rimaire)
- \u2705 **Gestion de profils \u00e9tendus** par type d'utilisateur
- \u2705 **Workflow de validation** des comptes Entreprise & Int\u00e9rimaire
- \u2705 **Tableau de bord Admin** avec KPIs temps r\u00e9el
- \u2705 **Tableau de bord Int\u00e9rimaire** avec compl\u00e9tude de profil
- \u2705 **Syst\u00e8me de notifications** (in-app + email)
- \u2705 **Upload d'avatars** avec stockage local (pr\u00eat S3)
- \u2705 **Audit trail** complet de toutes les actions
