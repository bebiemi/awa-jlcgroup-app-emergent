<product_requirements>
The JLC application is envisioned as a multi-actor interim management platform for the JLC Group, supporting Admin, Agency, Company, and Interim roles. Key functionalities include JWT + OAuth2 Google IDP authentication, roles/permissions, extended profiles with CRUD operations and avatar uploads per role, account validation, Admin/Interim dashboards, and a notification system. The backend uses FastAPI/MongoDB, and the frontend React 18 with Redux Toolkit/RTK Query.

**Implemented Features:**
1.  **Authentication & Registration:** Functional Google OAuth with initial role selection (Intérimaire/Société) for new users and automatic profile creation. Robust local registration with dynamic fields based on role, email validation, and password reset.
2.  **UI/UX:** A public landing page with offers, news, and calls to action. Enhanced login page with password reset and placeholders for other IDPs. Breadcrumbs for navigation. A persistent, retractable sidebar menu with role-based sections (Dashboard, Management, Account, Security). A login modal on the landing page for both local and Google OAuth authentication.
3.  **Admin User Management:** Backend endpoint for a paginated list of all users. Frontend user management page with table, pagination, search, filters, and action buttons (modify, delete, block) for users.
4.  **Admin Group & Profile Management:** Backend models for Permissions, Profiles, and Groups. Initial script to seed base permissions and profiles. Backend API endpoints for managing these security entities. Sidebar navigation for Sécurité section.
5.  **Multi-Factor Authentication (MFA):** Backend models for MFA (TOTP, Email OTP, Recovery Codes) and a dedicated MFA service. API routes for MFA setup, verification, and management. Integration of MFA into the local login flow.
</product_requirements>
