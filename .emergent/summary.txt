<product_requirements>
The JLC application aims to be a multi-actor interim management platform for the JLC Group, supporting Admin, Agency, Company, and Interim roles. It requires JWT + OAuth2 Google IDP authentication, roles/permissions, extended profiles with CRUD operations and avatar uploads per role, account validation, Admin/Interim dashboards, and a notification system. The backend uses FastAPI/MongoDB, and the frontend React 18 with Redux Toolkit/RTK Query.

**Implemented Features so far include:**
1.  **Authentication & Registration:** Functional Google OAuth and local registration with dynamic fields, email validation, and password reset.
2.  **UI/UX Enhancements:** Public landing page, enhanced login page, breadcrumbs, retractable sidebar with role-based navigation, and a login modal.
3.  **Admin User Management:** Backend endpoint for a paginated user list; frontend page with search, filters, and actions (modify, delete, block). Added super-admin ability to reset user MFA.
4.  **Admin Security Management:** Backend models and APIs for Permissions, Profiles, and Groups; initial seeding.
5.  **Multi-Factor Authentication (MFA):** Backend models, service, and API routes for TOTP, Email OTP, and recovery codes, integrated into local login. Frontend components for MFA setup, verification, and a Security Settings page.
6.  **Admin Dashboard & Navigation:** Dashboard displaying real-time KPIs, reorganized sidebar to categorize Users and Groups under Management. Admin Home button redirects to the admin dashboard.
7.  **Adaptive Landing Page:** Landing page now displays relevant actions (login/register or access dashboard) based on user login status.
8.  **Location Management (in progress):** A hierarchical location system (Country, Province, City, Arrondissement, Neighborhood) with CRUD, visibility, and custom fields. Backend models, API routes, and Gabon seed data are complete. Frontend API, management page with TreeView, and modals are being built, with a  integrated into the registration page.
9.  **Validation System (in progress):** A system for validating company registrations, including warnings for missing countries, assignable validators, and separate validation lists for users and companies. Backend routes and frontend pages are being built.
