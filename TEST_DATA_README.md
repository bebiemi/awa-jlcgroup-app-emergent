**Objectif:** Tester l'endpoint de missions recommandées

**API:**
```bash
# Login
TOKEN=$(curl -s -X POST "http://localhost:8000/api/auth/local/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"paul_oil","password":"Password123!"}' \
  | jq -r '.access_token')

# Get recommendations
curl -s "http://localhost:8000/api/missions/recommended?limit=10&min_score=50" \
  -H "Authorization: Bearer $TOKEN" | jq
```
